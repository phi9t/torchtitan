# GLM-5.3 Architecture Speedrun Queue Design

Generated by `experiments/glm53_arch_speedrun/queue/generate_cells.py`.
All Python generation and analysis is intended to run inside the `glm53_train` rootfs.

## Runnable Queue

- Token budget per run: `500000000` tokens.
- Science sequence length: `4096`; 4a also has the required `1024` replicate.
- Seeds: B0 and G use seeds `0,1,2`; all other runnable cells use seeds `0,1`.
- Each run requests one GPU, with the scheduler enforcing a 24 GiB process cap through the runner contract and requiring at least 30 GiB free before launch.

## 4c Fractional Factorial

The 4c generator is deterministic and nonregular:

1. Enumerate the full `2^4 x 3` design over F1 mHC, F2 positions, F3 mixer, F4 sparse, and F5 MTP.
2. With random seed `5303`, sample exactly 8 rows from each F4 sparse level.
3. Keep only samples balanced 12/12 on each two-level factor.
4. Accept the first candidate whose model matrix has full rank for the registered model: intercept, all main effects, all binary-binary two-way interactions, and all binary-by-sparse two-way interactions.

Declared resolution rule for this mixed-level nonregular fraction: the registered main-effect and two-way-interaction model must have no exact aliases among its columns. Under the effect coding below, the accepted design has:

- model rank `21/21`;
- operational resolution V for the preregistered analysis: no exact alias among the registered main and two-way terms;
- higher-order effects intentionally pooled into residual error, so effects are interpreted through the preregistered model only.

Effect coding:

- F1 mHC: off=-1, on=+1.
- F2 positions: RoPE=-1, NoPE=+1.
- F3 mixer: softmax=-1, KDA 3:1=+1.
- F5 MTP: off=-1, on=+1.
- F4 sparse uses two contrasts: dense=(+1,0), indexer=(-1,+1), indexer+IndexPool=(0,-1).

Registered model terms:

```text
I, mhc, positions, mixer, mtp, sparse_c1, sparse_c2, mhc:positions, mhc:mixer, mhc:mtp, positions:mixer, positions:mtp, mixer:mtp, mhc:sparse_c1, mhc:sparse_c2, positions:sparse_c1, positions:sparse_c2, mixer:sparse_c1, mixer:sparse_c2, mtp:sparse_c1, mtp:sparse_c2
```

## Deferred Freeze Rules

4d is not runnable at queue-generation time because the spec requires each dose sweep to run in the best context observed in 4a/4b. The analysis step must write `queue/frozen_4d_contexts.json` before any 4d state is initialized.

C1 is not runnable at queue-generation time because winners must be frozen after the scalar and behavior reads are available. The rule is predeclared: include every element whose mean validation CE improves over its declared comparison by more than `2 * std(B0 seed CE)` at the matched token budget.

MoE/F6 cells are not emitted by default. F6 is optional in the spec and requires a matched-active-parameter implementation and green S02 gate before it can be added with a separate generator revision.
