* Purpose

This is the literate scratchpad for the modded NanoGPT B200 rootfs Jupyter
environment. The source blocks execute in the =torchtitan-rootfs= Jupyter
kernel, so Python, Torch, CUDA, and shell commands run inside the bwrap rootfs
rather than on the host.

The companion verifier is:

#+end_src

* Modded NanoGPT FSDP Probe

The interactive default is one rank, because a single notebook kernel is not an
eight-rank =torchrun= launch. For interactive distributed work, keep the
notebook as rank 0 and launch ranks 1..7 as sidecar worker processes with a
shared rendezvous.

* Eight-rank interactive worker pattern

Start workers, run the distributed probe on all ranks, then shut the workers
down when the experiment is finished. Every collective in the rank 0 cell must
have matching work in the workers; otherwise the process group will block.

#+begin_src jupyter-python :eval never
from experiments.modded_nanogpt_b200 import hack

workers = hack.launch_jupyter_workers(world_size=8)
try:
    result = hack.distributed_probe(workers)
finally:
    hack.shutdown_jupyter_workers(workers)

result
#+end_src
