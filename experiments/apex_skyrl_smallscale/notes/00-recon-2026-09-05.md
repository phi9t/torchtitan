## Model reality check
- `Qwen/Qwen3.6-27B` (in HF cache): `model_type=qwen3_5`,
  `architectures=[Qwen3_5ForConditionalGeneration]`, has `layer_types` with
  `linear_attention` (GDN hybrid) + `full_attention` every 4th layer, is a VLM
  (`image_token_id`), 52 GB on disk. → This IS the gated-GDN thing to avoid,
  and won't fit the disk. Rejected.
- `torchtitan/assets/hf/Qwen3-1.7B`: `model_type=qwen3`,
  `architectures=[Qwen3ForCausalLM]`, 28 layers, hidden 2048, **no
  `layer_types` → pure attention, non-GDN, dense**, 3.8 GB, already local.
  → Chosen SFT base.

## Mercor released datasets — LICENSE BLOCKER for SFT
`mercor/ApexAgentsRecipe-ApexAgents480-EvalTraces` (and the TBench companion)
are **gated** and, per their card, CC-BY-4.0 **"for model evaluation only —
using them for training, fine-tuning, or parameter fitting is forbidden, as is
crawling or scraping."**
→ We CANNOT use these as SFT targets. They remain usable as an **eval**
reference only (reward reproduction script provided by Mercor).

### Trace format (for reference / for our own trace generation later)
Each run is a gzipped tarball; every trial is `<task_name>__<trial_id>/`:
- `config.json` — trial config (task path, agent/model settings)
- `result.json` — full result (config, timing, exception info)
- `agent/trajectory.json` — the agent message trajectory
- `agent/tito_transitions.json` — token-in/token-out transitions
  (training-format rollout)
- `verifier/reward.json` — reward + per-verifier judge grades/rationales
- Eval harness: Archipelago MCP agent, Harbor trial runner, `max_steps=250`,
  temp 1.0, `top_p=1.0`, `top_k` disabled, 262k context.
- Published scores (3-run mean ± std): 35B base MeanReward 28.69% / Pass@1
  13.96%; 35B trained 38.69% / 22.71%; 397B base 31.29% / 16.11%; 397B trained
  43.18% / 27.29%.

## verl SFT stack
`verl/verl/trainer/sft_trainer.py` (`SFTTrainer`, FSDP `TrainingWorker`) +
`verl/utils/dataset/multiturn_sft_dataset.py` (`MultiTurnSFTDataset`):
- Consumes **Parquet** with a `messages` column (multi-turn chat), optional
  `tools`, `images`, `videos`, `enable_thinking` columns.
- Trains on assistant turns (loss-masked), applies the tokenizer chat template.
- Single-node friendly; `max_length`, `pad_mode`, `truncation`, `max_samples`
  configurable. Examples under `verl/examples/sft`.
→ Data must be assembled as a `messages`-schema Parquet.
